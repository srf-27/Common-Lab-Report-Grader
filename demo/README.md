# 演示材料：化工专业实验报告评阅

一套可直接导入本系统的演示数据：**1 份网上下载的评分标准原件**、与其**同一来源的报告模板**、10 人花名册、5 份校准报告、5 份待评分报告。

> 学生姓名、学号、成绩均为虚构。评分标准、报告模板、实验讲义三个文件均从华东理工大学化工实验教学中心官网下载，内容未作任何改写。

## 学科与实验

| 项 | 内容 |
|---|---|
| 学科 | 化学工程与工艺 |
| 课程 | 化学工程与工艺专业实验（2） |
| 实验 | 乙苯负压脱氢制苯乙烯全流程虚拟仿真实验 |
| 报告形式 | 仿真稳态数据记录 + 苯乙烯收率计算 + 三个拓展讨论题 |
| 来源单位 | 华东理工大学 化工学院 化工实验教学中心 |

## 为什么评分标准用的是"教学大纲"而不是那份"评分标准.pdf"

同一页面上还有一份 `化工实验报告评分标准_奉贤校区6个实验&徐汇校区8个实验.pdf`，但它的链接在网页源码里**没有 href**（只剩文件名文本，另外三份报告要求/内页文件同样如此），浏览器里点不动，也无法构造下载地址。为了满足“原件、不是我生成的”这一条，改用同一页面、同一课程、同一实验的**教学大纲 PDF**——它的第九节就是官方的成绩评定方法与评分表，不是二手材料。

## 演示步骤

1. `python run.py`，新建课程「化工 2301」。
2. 「评分细则」上传 `rubric/化学工程与工艺专业实验（2）教学大纲.pdf`。
3. 生成后检查维度：**只保留报告能体现的项**——原始数据、实验现象、数据处理、结果讨论、格式规范；把“预习思考、方案设计、课堂讨论、操作规范、自我评估”删掉或降权（保存时权重会自动归一到 100%）。这些项在大纲里属于课堂与预习成绩，报告里没有依据。
4. 「花名册」上传 `roster/花名册.xlsx`。
5. 「实验报告」上传 `reports/` 下 5 份，等待解析。
6. 「选择评分」勾选 5 份并开始评分；完成后终审其中几份，让案例库有数据。
7. 「评分校准」逐份上传 `calibration/` 下报告，按 `教师评分参考.csv` 填各维度等级。
8. 「评分结果」导出成绩 Excel。

## 已知现象：模板化报告会让相似度全部接近 1.0

实测这 10 份报告两两相似度 **0.99～1.00**。原因不是数据重复，而是：

- 报告由同一模板生成，正文前 400 字符全是标题、封面、章节名和表头；
- 系统默认的内置嵌入模型（MiniLM）对输入有截断，前 256 token 左右就被截掉，而这一段恰好是模板样板，10 份几乎逐字相同。

结果是“文档级单向量 + 模板化报告”这一组合下，相似度功能基本失效。演示时建议二选一：

1. 把 `config/config.yaml` 的 `grading.similarity_threshold` 与 `similarity_reject` 临时设为 `1.01`，关闭这轮提示；
2. 或把 `vector_store.embedding.backend` 换成 `openai`（`text-embedding-3-small` 一类），同时重新标定两个阈值。

这也是一个真实的工程结论：**要抓模板化报告的雷同，必须做段落级比对，整篇单向量不够**。

## 生成细则时可能遇到的两件事

1. **维度里混进“预习思考 / 课堂讨论 / 操作规范 / 自我评估”**：这是大纲表 7 的原样内容，不是模型编的。报告里没有依据，删掉即可。
2. **提示“模型未生成带标准文档位置（doc_ref）的维度”**：说明模型没把维度定位到“九、成绩评定方法 / 表 7”。换一个更强的模型重试，或在细则页手动新增维度后逐格“补全”。

## 重新生成

```bash
.venv/Scripts/python.exe demo/build.py
```

`content.py` 里改数据或文字，`build.py` 重新填模板；收率、表格、教师评分 CSV 与花名册一并重建。模板文件本身不改，只读不改写。
